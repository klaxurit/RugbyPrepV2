# UPPER_OFFSEASON_FORCE_BRIDGE_V1

- `status`: validated
- `version`: V1
- `cycle`: off_season
- `session_type`: upper
- `target_level`: performance
- `target_position_group`: front_row + back_three (common base with light accents)
- `equipment`: full_gym
- `target_duration`: 50-60 min

## Goal
- Densify upper-body force after the hypertrophy block without jumping straight into pre-season structure.
- Reduce volume from Hypertrophy while keeping pressing, pulling, vertical support, and shoulder robustness in place.
- Prepare the player to enter pre-season with more usable upper-body force and better shoulder tolerance.

## Session Identity
- This is a force-bridge upper session, not a hypertrophy accumulation day and not yet a pre-season force session.
- Rugby-specific through useful horizontal pressing, strong pulling, controlled vertical support, and shoulder-friendly structure.
- Do not turn this into a heavy max bench day or a giant accessory workout.

## Warm-Up
Warm-up is stored as a collapsible recommendation rather than a mandatory visible block.

### Recommended warm-up
- `thoracic rotation` `1x6-8/side`
- `scap push-up` `1x8`
- `band pull-apart` `1x10`
- `2 progressive ramp-up sets` on the main press

### Notes
- Keep this practical and short.
- The player should feel ready for denser upper work, not like they are about to max out.
- If they already have a reliable upper warm-up, they can keep it.

## Visible Blocks

### Block 1 - Main Upper Force Bridge
- Format: `4 work sets`, `2-3 min` rest between sets
- Exercise A: `Bench Press` `4x5`
- Coaching notes:
  - Keep the bench around `RPE 6-8`.
  - This is the anchor force-bridge press of the session.
  - The goal is to feel stronger and denser than in Hypertrophy, not to chase grinders.
  - Fallback options:
    - A: `Neutral-Grip DB Bench Press`

### Block 2 - Main Pull / Secondary Push Pair
- Format: `3 rounds`, `90-120s` rest after the pair
- Exercise A: `Chest-Supported Row` `3x6-8`
- Exercise B: `Incline DB Bench Press` `3x6-8`
- Coaching notes:
  - This block keeps meaningful upper support work while volume comes down from Hypertrophy.
  - The row should stay strict and strong.
  - The incline press should support force-bridge intent, not become a second heavy bench.
  - Fallback options:
    - A: `Single-Arm DB Row`
    - B: `Machine Chest Press`

### Block 3 - Vertical Support Pair
- Format: `3 rounds`, `75-90s` rest after the pair
- Exercise A: `Seated DB Overhead Press` `3x6`
- Exercise B: `Neutral-Grip Lat Pulldown` `3x8`
- Coaching notes:
  - This block keeps vertical push/pull support in place as force rises.
  - Keep both movements clean, controlled, and submaximal.
  - This is still support volume, not the center of the session.
  - Fallback options:
    - A: `Half-Kneeling Landmine Press`
    - B: `Assisted Neutral-Grip Pull-Up`

### Block 4 - Arm / Shoulder Continuity
- Format: `2 rounds`, `45-60s` rest after the pair
- Exercise A: `Hammer Curl` `2x8-10`
- Exercise B: `Face Pull` `2x10-12`
- Coaching notes:
  - This block keeps simple arm and shoulder continuity while total session volume narrows.
  - Arm isolation volume is intentionally reduced from Hypertrophy.
  - Triceps are now loaded primarily through the main pressing patterns.
  - Keep everything honest and submaximal.
  - This should feel useful, not like a finisher challenge.

## Progression Rules
- `S9`: establish denser reference loads after Hypertrophy.
- `S10`: add load only if pressing and pulling still feel cleaner and stronger than the previous phase.
- Progress force expression, not fatigue.
- If fatigue rises, reduce Block 4 first, then reduce one round from Block 3.
- Keep Blocks 1 and 2 as the structural priorities of the session.

## Position Accent
- This session is still mostly common.
- `Front_row` accent:
  - slightly more bracing and posture on bench and row
  - slightly more interest in simple arm/support thickness
- `Back_three` accent:
  - slightly more fluid upper rhythm and shoulder freedom
  - slightly more attention to clean vertical support movement
- The skeleton remains identical for both groups.

## Injury Substitutions

### Shoulder pain
- Remove:
  - `Bench Press`
  - `Incline DB Bench Press`
  - `Seated DB Overhead Press`
- Replace with:
  - `Neutral-Grip DB Bench Press`
  - `Machine Chest Press`
  - `Half-Kneeling Landmine Press`
- Rehab finisher:
  - `band external rotation`
  - `serratus reach`
  - `scap push-up`

### Knee pain
- Remove:
  - none by default in this upper session unless setup is clearly aggravating
- Replace with:
  - seated variation if standing setup is uncomfortable
- Rehab finisher:
  - none by default in this upper session unless symptoms require it

### Low back pain
- Remove:
  - unsupported row alternatives if posture breaks
  - `Seated DB Overhead Press` only if trunk support is poor
- Replace with:
  - `Chest-Supported Row`
  - `Half-Kneeling Landmine Press`
- Rehab finisher:
  - breathing and trunk stiffness work

## Coaching Warnings
- This session should feel denser than Hypertrophy, not more punishing.
- Do not let the lower accessory volume tempt the player into chasing max bench numbers.
- Do not let the support blocks drift into hypertrophy fluff.
- The bridge works only if the player arrives stronger and cleaner, not beat up, into pre-season.
