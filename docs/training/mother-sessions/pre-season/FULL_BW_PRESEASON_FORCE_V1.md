- `status`: validated
- `version`: V1
- `cycle`: pre_season
- `session_type`: full
- `target_level`: builder
- `target_position_group`: front_row + back_three (phase 1 common base)
- `equipment`: bodyweight
- `target_duration`: 50-60 min

## Goal
- Whole-body force support for 3x/week pre-season phase 1 without gym.
- Pair hinge force with push/pull fundamentals and rugby finisher.

## Session Identity
- Full-body force construction — complements lower/upper split days.
- **Calibration** : nordiques stricts, pompes lestées, tractions propres si barre dispo.

## Warm-Up
Warm-up is stored as a collapsible recommendation rather than a mandatory visible block.

### Recommended warm-up
- `ankle rocks` `1x8/side`
- `glute bridge` `1x8`
- `scap push-up` `1x8`
- `bodyweight squat` `1x8`
- `2 progressive ramp-up sets` ``

## Visible Blocks

### Block 1 - Hinge Force
- Format: `3 work sets`, `2-3 min` rest between sets
- Exercise A: `Nordic Eccentric` `3x5`
- Coaching notes:
  - Hinge force — nordiques stricts ou RDL si haltères disponibles.

### Block 2 - Push / Pull Pair
- Format: `3 rounds`, `90-120s` rest after the pair
- Exercise A: `Decline Push-Up` `3x6-8`
- Exercise B: `Rowing inversé pieds surélevés` `3x6-8/side`
- Coaching notes:
  - Upgrade A: dumbbell bench if DB + bench.
  - Upgrade B: `Neutral-Grip Pull-Up` if bar available.

### Block 3 - Hip / Rotation
- Format: `3 rounds`, `75-90s` rest after the pair
- Exercise A: `Single-Leg Glute Bridge` `3x6-8/side`
- Exercise B: `Band Rotation Explosive` `2-3x6-8/side`
- Coaching notes:
  - Upgrade A: hip thrust on bench if DB + bench available.

### Block 4 - Finisher
- Format: `2 rounds`, `45-60s` rest
- Exercise A: `Bear Crawl` `15-20m`
- Exercise B: `Copenhagen Plank` `20-30s/side`
- Coaching notes:
  - Bear crawl: fast posture, scrum-like projection.
  - Upgrade A: `Farmer Carry` if DB/KB available.

## Progression Rules
- `W4` deload: cut Block 4, then one round from Block 3.
- Never sacrifice hinge or push quality for finisher volume.
