## Goal
- Phase 2 speed-power: contrasted accelerations, plyometrics, upper ballistics, COD.
- Higher intent than intro speed session — still terrain-first and low fatigue.

## Session Identity
- 4th session option weeks 5-8 — complements force-power gym/BW days.

## Warm-Up
Warm-up is stored as a collapsible recommendation rather than a mandatory visible block.

### Recommended warm-up
- `ankle rocks` `1x8/side`
- `A-skip` `1x10m`
- `wall drill march` `1x6/side`
- `2 progressive rehearsal reps` ``

## Visible Blocks

### Block 1 - Contrasted Acceleration
- Format: `4-5 rounds`, `2-3 min` rest between rounds
- Exercise A: `Resisted Acceleration` `8-10m`
- Exercise B: `Short Acceleration Sprint` `10-20m`
- Coaching notes:
  - Band resisted if available; falling start fallback.
  - Full rest — quality over density.

### Block 2 - Plyometrics
- Format: `3 rounds`, `90-120s` rest after the trio
- Exercise A: `Countermovement Jump` `2-3 reps`
- Exercise B: `Broad Jump` `2 reps`
- Exercise C: `Lateral Bound` `2/side`
- Coaching notes:
  - CMJ: max height, clean landing.
  - Control total contacts across the week.

### Block 3 - Upper Ballistic
- Format: `3 rounds`, `90s` rest after the pair
- Exercise A: `Plyo Push-Up` `4 reps`
- Exercise B: `Band Rotation Explosive` `3-4/side`
- Coaching notes:
  - Explosive trunk — hips drive rotation.

### Block 4 - COD
- Format: `3 rounds`, `60s` rest between reps
- Exercise A: `Acceleration to Lateral Shuffle to Sprint` `3x5m`
- Coaching notes:
  - Defensive shuffle into re-sprint — rugby COD pattern.

## Progression Rules
- `W4` deload: cut Block 4 reps first.
- Do not chase contacts if landings degrade.
