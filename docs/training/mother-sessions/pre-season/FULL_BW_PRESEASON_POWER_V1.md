## Goal
- Phase 3 full-body power — swing/hinge speed, plyo push, explosive pull.
- Short activation finisher before in-season transition.

## Session Identity
- Power phase full — low volume, high intent, rugby activation finish.

## Warm-Up
Warm-up is stored as a collapsible recommendation rather than a mandatory visible block.

### Recommended warm-up
- `glute bridge` `1x8`
- `pogo hops` `1x8`
- `scap push-up` `1x8`
- `2 progressive ramp-up sets` ``

## Visible Blocks

### Block 1 - Full Body Contrast
- Format: `3 rounds`, `2 min 30` rest between rounds
- Exercise A: `Squat Jump` `3x3`
- Exercise B: (contrast) `Broad Jump` `3 reps`
- Coaching notes:
  - Saut explosif — variante A : `Banded KB Swing` si élastique ou KB disponibles.

### Block 2 - Explosive Push / Pull
- Format: `3 rounds`, `90s` rest after the pair
- Exercise A: `Archer Push-Up` `3x3-4/side @ RIR 1-2`
- Exercise B: `Neutral-Grip Pull-Up` `3x3-4 @ RIR 1-2`
- Coaching notes:
  - Archer push-up (not decline/plyo — reserved for UPPER this week).
  - Pull-ups (not inverted row — reserved for UPPER this week).
  - Fallback A: `Chair Dip`. Fallback B: `Face Pull Band`.

### Block 3 - Activation
- Format: `2 rounds`, `45s` rest
- Exercise A: `A-Skip` `2x10m`
- Exercise B: `Side Plank` `2x15s/side`
- Coaching notes:
  - A-skip: stiff ankle, rhythmic acceleration posture.
  - Upgrade B: `Pallof Press Hold` if band available.

## Progression Rules
- Keep total session crisp — cut Block 3 before reducing contrast intent.
