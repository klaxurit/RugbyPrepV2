# Weekly Templates Off-Season

This document defines the first weekly structure for the off-season mother-session system.

Goal:
- cover the missing annual phase between in-season and pre-season
- keep the weekly format simple for amateur rugby players
- support `2x` and `3x` weekly S&C formats
- treat conditioning as a companion module, not as a second full system

---

## 1. Base Weekly Logic

### Recovery phase (`S1-S2`)

#### 2 sessions per week
- Session 1: `Full Recovery A`
- Session 2: `Full Recovery B`

This is the default V1 architecture for the first two off-season weeks.

Important:
- no `3x/week` default is planned here
- these two weeks are for regeneration and movement re-entry, not for rebuilding volume quickly

### Transition / Hypertrophy / Force-Bridge (`S3-S10`)

#### 2 sessions per week
- Session 1: `Lower`
- Session 2: `Upper`

#### 3 sessions per week
- Session 1: `Lower`
- Session 2: `Upper`
- Session 3: `Full`

This is the default V1 architecture for the main off-season build.

### Note for `2x/week` players
- `Lower + Upper` is the minimum effective dose, not the full off-season model.
- If `20-30 min` of extra time becomes available, prefer:
  - one simple conditioning exposure
  - one short trunk / groin / lower-leg micro-block
  - over forcing a third full gym session
- In practice, consistency across `8-10 weeks` matters more than trying to imitate a `3x/week` player.

---

## 2. Standard Timeline

### Standard V1 off-season
- `S1-S2`: `Recovery`
- `S3-S4`: `Transition`
- `S5-S8`: `Hypertrophy`
- `S9-S10`: `Force-Bridge`

### Short off-season (`8 weeks`)
- keep `S1-S2` as `Recovery`
- keep `S3-S4` as `Transition`
- reduce `Hypertrophy` to `S5-S7`
- use `S8` as `Force-Bridge Intro`

Important V1 rule:
- do not delete recovery completely just because the window is shorter
- the first block to compress is hypertrophy volume, not recovery/re-entry

---

## 3. Phase Logic

### Phase 1 — Recovery (`S1-S2`)
Use:
- `FULL_OFFSEASON_RECOVERY_A_V1`
- `FULL_OFFSEASON_RECOVERY_B_V1`

Intent:
- unload the player after the season
- restore movement quality and tissue tolerance
- reintroduce training without performance pressure

Conditioning companion:
- `2x 20-30 min zone 2`
- walking, bike, easy run, swim

### Phase 2 — Transition (`S3-S4`)
Use:
- `LOWER_OFFSEASON_TRANSITION_V1`
- `UPPER_OFFSEASON_TRANSITION_V1`
- `FULL_OFFSEASON_TRANSITION_V1`

Intent:
- rebuild basic patterns
- restore tolerance to squat, hinge, push, pull
- prepare the higher-volume hypertrophy block

Conditioning companion:
- `2x 25-35 min zone 2`
- or `1x zone 2 + 1x light tempo`

### Phase 3 — Hypertrophy (`S5-S8`)
Use:
- `LOWER_OFFSEASON_HYPERTROPHY_V1`
- `UPPER_OFFSEASON_HYPERTROPHY_V1`
- `FULL_OFFSEASON_HYPERTROPHY_V1`

Intent:
- rebuild useful rugby muscle mass
- raise structural tolerance
- create the base that will later be converted in pre-season

Conditioning companion:
- `2x` aerobic base work
- or `1x aerobic base + 1x tempo`
- avoid letting conditioning interfere with the main lower-body volume

### Phase 4 — Force-Bridge (`S9-S10`)
Use:
- `LOWER_OFFSEASON_FORCE_BRIDGE_V1`
- `UPPER_OFFSEASON_FORCE_BRIDGE_V1`
- `FULL_OFFSEASON_FORCE_BRIDGE_V1`

Intent:
- reduce volume slightly
- intensify the main patterns
- create a clean handoff into pre-season

Conditioning companion:
- `1-2` exposures maximum
- keep aerobic maintenance
- optional short acceleration technique if recovery is good

---

## 4. Position Logic

### Recovery / Transition
- sessions stay largely common
- use position accents only inside the session

### Hypertrophy
- sessions still stay common in V1
- accents become a bit more visible:
  - `front_row`: bracing, carry, neck, squat/hinge support
  - `back_three`: unilateral, lower-leg, rotation, trunk control

### Force-Bridge
- sessions still share the same mother-session skeleton
- position notes can become more explicit
- do not create a full position split in V1 unless the value is obvious

Recommended V1 rule:
- common off-season base
- stronger positional split later in pre-season and in-season

---

## 5. Conditioning Companion

Conditioning off-season V1 is intentionally simple.

It should be prescribed inside the weekly template, not as a separate mother-session library.

### Allowed V1 conditioning formats
- `Zone 2` steady work
- `Tempo run`
- optional short acceleration technique in `Force-Bridge`

### What this is not
- not a second fully-authored system
- not a detailed injury-substitution matrix
- not a reason to double the scope of the off-season project

### Simple reduction rule
- if lower-body fatigue is high, reduce conditioning before cutting the main S&C session
- if the player only has time for one add-on, keep aerobic base before tempo

---

## 6. Recommended Weekly Placement

The template defines what to do in a week. Placement defines when to do it.

Key rules:
- separate the hardest lower-body work from the hardest conditioning exposure
- keep at least `48h` between lower-heavy gym sessions when possible
- in off-season, frequency consistency matters more than a perfect weekday setup

### Example — `2x/week`
- Monday or Tuesday: `Lower`
- Thursday or Friday: `Upper`
- conditioning on a separate easy day if possible

### Example — `3x/week`
- Monday: `Lower`
- Wednesday: `Upper`
- Friday or Saturday: `Full`

### Recovery phase example
- Tuesday: `Full Recovery A`
- Friday: `Full Recovery B`

The placement rule matters more than the day names:
- lower first
- upper in the middle
- full later
- conditioning easy enough not to ruin the next lift

---

## 7. Fatigue Override

The off-season should not become an excuse to accumulate junk fatigue.

If fatigue is high:
- reduce conditioning first
- remove optional pump/reward work second
- reduce one support block third
- keep one main pattern exposure if movement quality is still good

Simple V1 rule:
- `normal fatigue` -> keep the planned weekly structure
- `high fatigue in Recovery or Transition` -> keep only `2x/week`
- `high fatigue in Hypertrophy` -> keep main blocks, cut accessory volume
- `high fatigue in Force-Bridge` -> reduce support work, keep the main lift quality

---

## 8. Transition Logic

### End of season -> Off-season
- Off-season should be proposed when:
  - no match has been played for more than `3 weeks`
  - or the player explicitly marks the season as finished

### Off-season -> Pre-season
- Pre-season should be proposed when the player enters the final `12 weeks` before return to team training / first match
- if the player completed off-season normally, they enter `Pre-season S1`
- if the player skipped most of off-season, start pre-season more conservatively
- if the player completed less than `4 weeks` of structured off-season work:
  - keep a `2-week` conservative ramp at the start of pre-season
  - reduce `Block 1` loads by around `10-15%`
  - keep all volumes at the low end of prescribed ranges for `S1-S2`

### Important product rule
- never switch phases silently
- always ask for user confirmation
- always allow manual override

## 10. Implementation Notes

Later in the app, weekly selection can follow a simple path:
1. detect season state (`off-season`, `pre-season`, `in-season`)
2. detect available off-season duration (`standard` or `short`)
3. detect weekly frequency (`2` or `3`)
4. detect current off-season phase
5. detect fatigue override
6. select the corresponding mother sessions
7. add the conditioning companion prescription
8. apply equipment and injury substitutions using the automatic alternatives matrix

This keeps the off-season system:
- coach-led
- readable
- annual-cycle coherent
- and compatible with the pre-season and in-season structures already validated
