# Accélération rugby (slot Speed)

> Cluster **nouveau**. Calibre le Speed : accels + repos, **pas** du HIIT
> burpees. Cahill 2020 (déjà en `energy-systems.md`) = soutien luge, pas canon.

## Canon

Revue 2025 (semi-pro / pro) : mieux pour le sprint rugby = force + plyo +
travail spécifique ; small-sided games pour l’agilité ; **luge / sprint
résisté** surtout pour l’accélération courte, peu pour la Vmax.

**Source** : *Optimising Sprint Performance in Rugby…* (2025).
*Journal of Functional Morphology and Kinesiology*, 10(1), 51.
https://doi.org/10.3390/jfmk10010051

Soutien charge (un rôle) : luge lourde (~50 % perte de Vmax), volume égalisé —
gains d’accélération (Botter et al. 2025 JSCR). Individualiser la charge si
matériel (Maviel et al. 2026 ; profil Morin/Samozino).

## Décision RugbyPrep

- Slot Speed dédié ; ne pas l’empiler avec un Lower lourd + club le même jour
  (`product-decisions.md`).
- Amateur sans luge : 3–6 accels 10–20 m, repos 2–3 min, intention max.
- Luge %BW : seulement si matériel ; pas un rail 130 % BW (Instagram).
- Vague 2 : **pas** de rewrite Speed. Vague 3 = B3 de la revue de cycle.
