## Goal
- Bridge Recovery and off-season build with a controlled full-body bodyweight session.
- Complement Lower/Upper Transition without repeating their main patterns exactly.
- Reintroduce hinge, push/pull, locomotion, and trunk support.

## Session Identity
- Transition full-body — not recovery circuit, not hypertrophy day.
- Rugby-specific hinge, upper support, trunk, and light contact-prep accents.

## Warm-Up
Warm-up is stored as a collapsible recommendation rather than a mandatory visible block.

### Recommended warm-up
- `ankle rocks` `1x8/side`
- `adductor rock-back` `1x8/side`
- `scap push-up` `1x8`
- `glute bridge` `1x8`
- `2 progressive ramp-up sets` ``

### Notes
- Short — ready to train moderately.

## Visible Blocks

### Block 1 - Hinge / Squat Light Pair
- Format: `3 rounds`, `90s` rest after the pair
- Exercise A: `Good Morning` `3x8 @ RER 1-2`
- Exercise B: `Reverse Lunge Bodyweight` `3x8/side @ RER 1-2`
- Coaching notes:
  - Hinge pattern with bodyweight good morning; reverse lunge (not BW squat — already on LOWER this week) `RPE 5-6`.
  - Fallback: `Glute Bridge` if low back sensitive.

### Block 2 - Push / Pull Pair
- Format: `3 rounds`, `90s` rest after the pair
- Exercise A: `Chair Dip` `3x8-10 @ RER 1-2`
- Exercise B: `Face Pull Band` `3x10-12 @ RER 1-2`
- Coaching notes:
  - Chair dips (not decline push-up — reserved for UPPER this week).
  - Face pull (not inverted row — reserved for UPPER this week).
  - Fallback A: `Archer Push-Up`. Fallback B: `Inverted Row Standard` only if UPPER was skipped.

### Block 3 - Rugby Light Finisher
- Format: `2 rounds`, `60s` rest after the pair
- Exercise A: `Bear Crawl` `2x15m`
- Exercise B: `Side Plank` `2x15s/side`
- Coaching notes:
  - Athletic but submaximal — not a conditioning test.
  - Front_row: optional 1 round neck isometric (hand) after planks if no pain.

## Progression Rules
- `S3`–`S4`: progress movement quality and slightly harder BW variants before adding rounds.
- Do not add extra blocks — stay transition volume.

## Coaching Warnings
- Not an everything day or sneaky volume monster.
- If beat up, reduce to 2 rounds on Blocks 1–2.
