| Situation | Fichiers |

| Update volume / dosage | `evidence-clusters.md` + `product-decisions.md` + `load-budgeting.md` |
| Contrastes | `evidence-clusters.md` + `strength-methods.md` |
| Nordic / ischios | `evidence-clusters.md` + `injury-prevention.md` |

| RER / échec | `evidence-clusters.md` + Robinson dans `strength-methods.md` |
| Semaine de match / club | `contact-load.md` + `product-decisions.md` |
| Cou / commotion préventive | `neck-training.md` (1 fichier) |
| Speed / accels | `sprint-acceleration.md` + `product-decisions.md` |
| Rails sécurité | `evidence-register.md` + `medical-red-flags.md` si douleur |

Règle : si le sujet a un cluster dans `evidence-clusters.md`, commencer par lui.
