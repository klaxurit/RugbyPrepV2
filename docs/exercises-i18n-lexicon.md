# Lexique exercices Mother Sessions — EN → FR

> **Contexte** : 39 sessions × 3 cycles annuels (off-season, pre-season, in-season).
> Référence pour la traduction française à brancher derrière le futur toggle EN/FR (paramètres utilisateur).
> Les noms anglais (colonne **Nom EN**) sont conservés tels quels en code — la colonne **FR** est la version affichée quand le toggle est sur français.
>
> **Légende source** : `main` = exercice principal d'un bloc · `alt` = fallback / option de remplacement · `warm-up` = échauffement · `réhab` = finisher / substitution blessure.
> **Légende cycle** : `off` = off-season · `pre` = pre-season · `in` = in-season.

## Notes

- Total : **157 entrées uniques** extraites depuis `src/data/motherSessions.generated.ts` (parser : `/tmp/extract_exercises.mjs`).
- La dédup est insensible à la casse (`Back Squat` = `back squat`) ; la forme retenue est la plus capitalisée présente dans la source.
- Les options composées du type `A or B` (ex. `Zercher Carry or Farmer Carry`) ont été éclatées en deux entrées distinctes.
- Les directives non-exercices (`2 progressive ramp-up sets`, `3x6 @ 75%`, etc.) sont filtrées.
- Quelques entrées peuvent rester très génériques (`Carry`, `Landmine`, `Drop to Stick`) — à arbitrer pendant la traduction.
- 5 corrections d'incohérences appliquées (relecture 2026-05-11) :
  - §1.8 `single-leg glute bridge` → `Pont fessier unilatéral` (cohérence avec `Glute Bridge` → `Pont fessier`).
  - §2.33 `Copenhagen Plank` → garde `Copenhagen Plank` en FR (cohérence avec `Copenhagen Hold` gardé en EN).
  - §2.75 `low pogo hops` → `Petits pogo hops` (alignement EN `hops` ≠ FR `jumps`).
  - §2.89 `Pallof` → `Pallof` (match EN court — la source MD utilise le raccourci, à fixer en source plus tard si besoin).
  - §2.100 `RDL` → `RDL` (symétrie acronyme EN/FR, le terme est compris en gym FR).
