## 2. Règles volume (référence app)

### 3.2 Off-season Transition (S3–S4)

| Séance | Sets durs | Durée | Verdict |
|--------|-----------|-------|---------|
| Lower Trans | ~16 | 40–50 min | ✅ OK |
| Upper Trans | ~14 | 40–50 min | ✅ OK |
| Full Trans (3×) | ~18 | 45–55 min | ✅ OK limite |

**Incohérence mineure** : Bloc 3 Upper (bras + face pull) utile mais **non prioritaire rugby** — passer en optionnel si fatigue club.

---

### 3.3 Off-season Hypertrophie (S5–S8) — ⚠️ SURCHARGE

| Séance | Sets durs AVANT correction | Cap cible | Verdict |
|--------|---------------------------|-----------|---------|
| Lower Hyp | **~32–38** | 16–22 | ❌ Surchargé |
| Upper Hyp | **~40–48** | 16–22 | ❌ Surchargé |
| Full Hyp (3×) | **~28** | 18–22 | ⚠️ Limite |

**Problèmes identifiés** :
- Bloc 2 Lower : 4 tours × (4+4) = 32 sets jambes/postérieur en une séance
- Upper : 5 blocs cumulés (push + pull + vertical + bras + épaule) = bodybuilding, pas rugby
- Semaine 2× Lower+Upper = **>50 sets haut du corps** → incompatible charge club

**Corrections V1.1** :
- Lower Hyp B2 : **3 tours**, unilatéral **3 séries** fixes
- Lower Hyp B3 : **2 tours**
- Upper Hyp B2 : **3 tours**
- Upper Hyp B4–B5 : **optionnels** (couper en premier si fatigue)
- Full Hyp : conserver structure, pas de 4e bloc en 2×/sem

**Cohérence rugby** : patterns OK ; volume à ramener pour laisser place au rugby.

---

## 4. Accents par poste — Framework V1

### 4.1 Groupes (aligné `buildAthletePlanningInputs.ts`)

### 4.2 Priorités transfert rugby

| Besoin | front_row | back_three |
|--------|-----------|------------|
| **Nuque / contact** | ★★★★★ | ★★☆☆☆ |
| **Adducteurs / mêlée** | ★★★★★ | ★★★☆☆ |
| **Push horizontal / mêlée** | ★★★★★ | ★★★☆☆ |
| **Carry / grip** | ★★★★☆ | ★★★☆☆ |
| **Sprint / COD** | ★★★☆☆ | ★★★★★ |
| **Pull / plaquage** | ★★★★☆ | ★★★★★ |
| **Rotation / offload** | ★★★☆☆ | ★★★★☆ |

### 4.3 Bloc Position standard (à ajouter en fin de séance)

**Format commun** : `2 tours`, repos `45–60s`, **réduire en premier si fatigue**.

#### front_row — `BLOC_POSITION_FRONT_ROW`

| Slot | Exercice (tier 0 → upgrade) | Prescription |
|------|----------------------------|--------------|
| A — Nuque | Flexion iso main → extension iso → latéral (10s/direction) | `2×10s/direction` |
| B — Adducteurs | Copenhagen genou → Copenhagen long (banc) | `2×15–20s/côté` |
| C — Contact / grip | Farmer sac → dips lestés | `2×20m` ou `2×30s` |

*Upgrade bande* : `neck__flexion_iso__band`, `neck__extension_iso__band`, etc.

#### back_three — `BLOC_POSITION_BACK_THREE`

| Slot | Exercice | Prescription |
|------|----------|--------------|
| A — COD / vitesse | Shuffle défensif → bound latéral | `2×5m` ou `2×3/côté` |
| B — Trunk | Pallof bande → planche latérale | `2×15s/côté` |
| C — Pull rugby | Tractions / rowing explosif | `2×5` qualité |

*Nuque* : optionnel 1×10s flexion si plaquage fréquent.

### 4.4 Où placer le Bloc Position

| Cycle / séance | front_row | back_three |
|----------------|-----------|------------|
| Recovery | Optionnel léger (nuque 1 tour) | Skip |
| Transition | 1 tour nuque FR | Skip |
| Hypertrophie | Bloc 4 ou 5 (remplace bras optionnel FR) | Bloc 5 optionnel COD |
| Force-pont | Bloc 4 complet FR | Bloc 4 back_three |
| Pré-saison force | Bloc 4 | Bloc 4 allégé |
| In-season Full | Bloc 4 (comme full_gym FR) | EMOM finisher existant |
| Primer | Nuque 1 tour FR option | Skip |

## 6. Matrice validation humaine (checklist coach)

Pour chaque séance validée, cocher :

- [ ] Sets durs dans la fourchette §2 pour le niveau cible
- [ ] 6 patterns rugby couverts ou justifiés (intent du jour)
- [ ] Bloc Position présent si séance ≥ Transition
- [ ] front_row : nuque + adducteurs au moins 1×/semaine
- [ ] back_three : composante vitesse/COD 1×/semaine (in-season ou pré-saison)
- [ ] Durée tenable avec entraînement club (≤45 min in-season, ≤55 min off-season hyp)
- [ ] Deload semaine 4 : −30 % appliqué
- [ ] Aucun exercice requérant matériel absent du profil test
