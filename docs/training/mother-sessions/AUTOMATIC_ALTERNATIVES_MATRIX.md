# Automatic Alternatives Matrix

This document defines automatic exercise substitutions around the current mother sessions.

Purpose:
- keep the identity of the mother session intact
- replace exercises predictably when equipment is missing
- support common pain / injury contexts without rewriting full sessions
- prepare a future mapping layer for the app

Priority order for substitutions:
1. Keep the same training intent.
2. Keep the same main pattern if possible.
3. Reduce technical complexity before reducing specificity.
4. If pain is involved, protect the irritated area first, then preserve the session's intent as much as possible.

## 1. Upper Push

### Football Bar Bench Press
- Primary use:
  - front-row upper / full / primer
- Automatic alternative if unavailable:
  - `Neutral-Grip DB Bench Press`
- Standard fallback:
  - `Bench Press`
- Shoulder pain alternative:
  - `Landmine Press`
- Notes:
  - Prefer neutral-grip DB before classic barbell when the football bar is unavailable.
  - This keeps a more shoulder-friendly pressing angle.

## 8. Implementation Notes

Recommended mapping logic in the app, later:
1. Try exact mother-session exercise.
2. If unavailable, use `automatic alternative`.
3. If still unavailable, use `standard fallback`.
4. If pain/injury flag is present, override with the pain-specific alternative path.

Important:
- do not mix substitutions that change the whole identity of the block
- keep primer blocks low-volume and ballistic even after substitution
- keep full-body blocks a bit more muscular, but still in-season
